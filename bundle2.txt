# OSM Auto Squad — Android native

This project combines the Compose roster editor from `bundle2.txt` with the OCR / AccessibilityService foundation from `bundle.txt`.

## Included in this revision

- Native Android application using Kotlin, Jetpack Compose, ML Kit OCR and AccessibilityService.
- Formation editor for 4-3-3A and 5-2-3A.
- Twenty roster places: starting XI plus 9 substitutes.
- Position selection for substitutes and an “öncelikli yedek” flag.
- Preflight validation for the roster rules:
  - XI rating equals the selected target rating.
  - Starting XI age rule: non-OS positions 20–29; among the two OS players, one is 20–29 and one is 31+.
  - Priority substitutes: at least target rating and age 20–29.
  - Standard substitutes: at least 50 rating and age 15–50.
  - 9 substitute positions: 2 GK, 3 DF, 2 MD, 2 FW.
  - A target-rated SĞA cannot be a substitute.
- Automation handoff from the Compose roster to the AccessibilityService.
- Floating controls: BAŞLAT, DURAKLAT, DEVAM, DURDUR and TANI.
- After a pitch slot is selected, the service recognizes the category chooser and taps the blue + button inside the matching category row (Forvetler, Orta sahalar, Defanslar or Kaleciler). It does not tap the category heading itself. It then opens the player list/search step.
- OCR-based player-row matching checks name, age, position and available rating columns; duplicate matches or failed counter verification stop the run.
- For starting-XI slots, the service attempts to detect the green pitch area and maps the saved formation position into that area. If the pitch cannot be detected, it stops without tapping.
- For substitute slots, the service only proceeds when the Yedekler tab and the named slot are available through the Android accessibility tree. It does not guess substitute coordinates.

## Build

Push the project to a GitHub repository, then run **Actions → Build OSM Auto Squad APK → Run workflow**. The debug APK is uploaded as the `osm-auto-squad-debug-apk` artifact.

The repository does not include a Gradle wrapper binary. The workflow creates the wrapper using Gradle 8.7 before building.

## Phone setup

1. Install the debug APK.
2. Open the app and choose 4-3-3A or 5-2-3A.
3. Enter all 20 players, including age, rating and substitute position/priority status.
4. Open the Checklist tab and press **Otomasyon için hazırla**. Any roster rule errors must be fixed first.
5. Enable **OSM Auto Squad** under Android Accessibility settings.
6. Open OSM and go to the squad / pitch screen. Use the floating service panel and press **BAŞLAT**.
7. Keep an eye on the first run. Press **DURAKLAT** or **DURDUR** if the game screen looks different or unexpected.

## Known limitations — do not treat as production-verified

- This source revision has not been built on a real Android SDK or tested against the live OSM app UI in this environment. The GitHub Actions workflow is included, but an APK has not been generated here.
- OSM screen layouts and OCR text vary by app version, language, device and resolution. The pitch-region detection and normalized field points must be validated on the user's actual OSM screen before unattended use.
- Substitute placement depends on OSM exposing the bench tab and slot labels in the Accessibility tree. If those labels are unavailable, the service stops rather than tapping guessed coordinates.
- Goalkeeper rating is not independently compared because the older OCR row format did not expose a goalkeeper rating column. Name, age and position are still checked.
- There is not yet a verified transfer-price / available-budget parser. Do not run unattended with a valuable in-game budget until the budget guard is implemented and verified.
- Any player row with more than one strict candidate, a missing category, an unreadable counter, or an unverified add is treated as an error and stops the run.

The category + selection fix is based on the supplied OSM screenshot and still needs to be confirmed on the installed OSM version. This is an integrated development build, not a claim that all screen-specific automation is finished or field-tested.

package app.osmsquad

import org.json.JSONArray
import org.json.JSONObject

data class AutoPlayer(
    val role: String,
    val slot: String,
    val order: Int,
    val name: String,
    val age: Int,
    val club: String,
    val pos: String,
    val rating: Int,
    val col: String,
    val priority: Boolean
) {
    val key: String get() = "$order|$name|$age"
}

data class Squad(val formation: String, val target: Int, val players: List<AutoPlayer>)

object SquadIO {
    fun parse(json: String): Squad {
        val o = JSONObject(json)
        require(o.optInt("version") == 1) { "Otomasyon JSON sürümü desteklenmiyor" }
        val arr = o.getJSONArray("players")
        val list = (0 until arr.length()).map { i ->
            val q = arr.getJSONObject(i)
            AutoPlayer(q.getString("role"), q.getString("slot"), q.getInt("order"), q.getString("name"),
                q.getInt("age"), q.optString("club", ""), q.getString("pos"), q.getInt("rating"),
                q.optString("col", "o"), q.optBoolean("priority", false))
        }
        val s = Squad(o.getString("formation"), o.getInt("target"), list)
        validate(s)
        return s
    }

    fun validate(s: Squad) {
        val formation = Formations.all.firstOrNull { it.id == s.formation }
            ?: throw IllegalArgumentException("Diziliş geçersiz")
        require(s.players.size == 20) { "Toplam oyuncu 20 olmalı (${s.players.size})" }
        require(s.players.count { it.role == "XI" } == 11) { "İlk 11 sayısı 11 olmalı" }
        require(s.players.count { it.role == "SUB" } == 9) { "Yedek sayısı 9 olmalı" }
        require(s.players.all { it.role == "XI" || it.role == "SUB" }) { "Oyuncu rolü geçersiz" }
        require(s.players.map { it.key }.toSet().size == 20) { "Çift oyuncu kaydı var" }
        require(s.players.map { fold(it.name) }.toSet().size == 20) { "Tekrarlanan oyuncu adı var" }
        require(s.target in 1..100) { "Hedef reyting 1-100 olmalı" }
        val xi = s.players.filter { it.role == "XI" }
        val subs = s.players.filter { it.role == "SUB" }
        require(xi.map { it.slot }.toSet() == formation.slots.map { it.id }.toSet()) { "İlk 11 yuvaları dizilişle uyuşmuyor" }
        require(subs.map { it.slot }.toSet() == Formations.SUBS.map { it.id }.toSet()) { "Yedek yuvaları eksik veya tekrarlı" }
        val xiBySlot = xi.associateBy { it.slot }
        formation.slots.forEach { slot ->
            val player = xiBySlot[slot.id] ?: error("Eksik ilk 11 yuvası: ${slot.label}")
            require(player.pos == slot.label) { "${slot.label} yuvasında yanlış pozisyon: ${player.pos}" }
        }
        s.players.forEach { p ->
            require(p.name.isNotBlank() && p.age in 1..60 && p.rating in 1..100) { "Oyuncu bilgisi geçersiz: ${p.name}" }
            require(Formations.groupOfPosition(p.pos) != null) { "Pozisyon tanınmadı: ${p.pos}" }
        }
        xi.forEach {
            require(it.rating == s.target) { "${it.name}: ilk 11 reytingi hedef ${s.target} olmalı" }
            if (it.pos != "OS") require(it.age in 20..29) { "${it.name}: ilk 11 yaşı 20-29 olmalı" }
        }
        val os = xi.filter { it.pos == "OS" }
        require(os.size == 2 && os.count { it.age in 20..29 } == 1 && os.count { it.age >= 31 } == 1) {
            "İlk 11'deki iki OS oyuncusundan biri 20-29, diğeri 31+ yaşında olmalı"
        }
        val subSlotGroup = Formations.SUBS.associate { it.id to it.group }
        subs.forEach { p ->
            require(subSlotGroup[p.slot] == Formations.groupOfPosition(p.pos)) { "${p.name}: yedek yuvası/pozisyon grubu uyuşmuyor" }
            if (p.priority) {
                require(p.rating >= s.target && p.age in 20..29) { "Öncelikli yedek ${p.name}: hedef reyting ve 20-29 yaş gerekli" }
            } else {
                require(p.rating >= 50 && p.age in 15..50) { "Normal yedek ${p.name}: en az 50 reyting ve 15-50 yaş gerekli" }
            }
            require(!(p.pos == "SĞA" && p.rating == s.target)) { "Hedef reytingli SĞA yedek olamaz: ${p.name}" }
        }
        require(subs.count { Formations.groupOfPosition(it.pos) == "GK" } == 2 &&
            subs.count { Formations.groupOfPosition(it.pos) == "DF" } == 3 &&
            subs.count { Formations.groupOfPosition(it.pos) == "MD" } == 2 &&
            subs.count { Formations.groupOfPosition(it.pos) == "FW" } == 2) {
            "Yedek dağılımı 2 KL, 3 DEF, 2 ORT, 2 FOR olmalı"
        }
    }

    private fun fold(s: String): String = java.text.Normalizer.normalize(s.replace('ı', 'i').replace('İ', 'I'), java.text.Normalizer.Form.NFD)
        .replace(Regex("\\p{M}"), "").lowercase().replace(Regex("[^a-z0-9]"), "")
}

fun copyText(ctx: Context, t: String) {
    val cm = ctx.getSystemService(Context.CLIPBOARD_SERVICE) as ClipboardManager
    cm.setPrimaryClip(ClipData.newPlainText("oyuncu", t))
    Toast.makeText(ctx, "Kopyalandı: $t", Toast.LENGTH_SHORT).show()
}

fun openOsm(ctx: Context) {
    for (pkg in listOf("com.gamebasics.osm", "com.pengyou.cloneapp")) {
        val i = ctx.packageManager.getLaunchIntentForPackage(pkg)
        if (i != null) {
            i.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
            ctx.startActivity(i)
            return
        }
    }
    try {
        val i = Intent(Intent.ACTION_VIEW, Uri.parse("https://play.google.com/store/apps/details?id=com.gamebasics.osm"))
        i.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
        ctx.startActivity(i)
    } catch (e: Exception) {
        Toast.makeText(ctx, "OSM açılamadı", Toast.LENGTH_SHORT).show()
    }
}

@Composable
fun App(st: SquadState) {
    var tab by remember { mutableStateOf(0) }
    var editSlot by remember { mutableStateOf<Slot?>(null) }
    var pick by remember { mutableStateOf(st.formationId == null) }

    if (pick || st.formation == null) {
        FormationScreen(st) { pick = false }
    } else {
        Scaffold(
            topBar = { Header(st) },
            bottomBar = {
                NavigationBar {
                    val items = listOf("Saha" to "⚽", "Yedekler" to "🪑", "Liste" to "✅", "JSON" to "💾")
                    items.forEachIndexed { i, it ->
                        NavigationBarItem(
                            selected = tab == i, onClick = { tab = i },
                            icon = { Text(it.second) }, label = { Text(it.first) }
                        )
                    }
                }
            }
        ) { pad ->
            Box(Modifier.padding(pad)) {
                when (tab) {
                    0 -> PitchScreen(st, onPick = { pick = true }, onTap = { editSlot = it })
                    1 -> SubsScreen(st, onTap = { editSlot = it })
                    2 -> ChecklistScreen(st, onEdit = { editSlot = it })
                    else -> JsonScreen(st)
                }
            }
        }
    }
    editSlot?.let { s -> PlayerDialog(st, s) { editSlot = null } }
}

@Composable
fun FormationScreen(st: SquadState, onDone: () -> Unit) {
    var confirm by remember { mutableStateOf<Formation?>(null) }
    var targetText by remember { mutableStateOf(st.target.toString()) }
    Column(Modifier.fillMaxSize().verticalScroll(rememberScrollState()).padding(16.dp)) {
        Text("Diziliş seç", fontSize = 24.sp, fontWeight = FontWeight.Bold)
        Spacer(Modifier.height(8.dp))
        OutlinedTextField(
            value = targetText,
            onValueChange = { t ->
                targetText = t
                val v = t.toIntOrNull()
                if (v != null && v in 1..100) st.updateTarget(v)
            },
            label = { Text("Hedef reyting (1-100)") }, singleLine = true,
            keyboardOptions = KeyboardOptions(keyboardType = KeyboardType.Number),
            modifier = Modifier.fillMaxWidth()
        )
        Spacer(Modifier.height(12.dp))
        Row(Modifier.fillMaxWidth(), horizontalArrangement = Arrangement.spacedBy(12.dp)) {
            for (f in Formations.all) {
                Card(
                    Modifier.weight(1f).clickable {
                        val hasXi = st.players.keys.any { it.startsWith("xi") }
                        if (st.formationId != null && st.formationId != f.id && hasXi) confirm = f
                        else { st.setFormation(f.id); onDone() }
                    },
                    border = if (st.formationId == f.id) androidx.compose.foundation.BorderStroke(3.dp, Color(0xFF0D47A1)) else null
                ) {
                    Column(Modifier.padding(10.dp), horizontalAlignment = Alignment.CenterHorizontally) {
                        MiniPitch(f)
                        Spacer(Modifier.height(6.dp))
                        Text(f.id, fontSize = 20.sp, fontWeight = FontWeight.Bold)
                    }
                }
            }
        }
        if (st.formation != null) {
            Spacer(Modifier.height(16.dp))
            Button(onClick = onDone, modifier = Modifier.fillMaxWidth()) { Text("Mevcut dizilişle devam: ${st.formationId}") }
        }
    }
    confirm?.let { f ->
        AlertDialog(
            onDismissRequest = { confirm = null },
            title = { Text("Diziliş değişsin mi?") },
            text = { Text("İlk 11'deki oyuncular silinir (yedekler kalır).") },
            confirmButton = { TextButton(onClick = { st.setFormation(f.id); confirm = null; onDone() }) { Text("Değiştir") } },
            dismissButton = { TextButton(onClick = { confirm = null }) { Text("İptal") } }
        )
    }
}

            Text("⚠ ${st.slotById(k)?.label}: ${st.players[k]?.name} — $v", color = Color(0xFFEF6C00), fontSize = 13.sp)
        }
        Text("Kurallar otomasyon hazırlığında doğrulanır; ihlal varsa otomasyon ayarı oluşturulmaz.",
            fontSize = 11.sp, color = Color.Gray)
    }
}

@Composable
fun ChecklistScreen(st: SquadState, onEdit: (Slot) -> Unit) {
    val ctx = LocalContext.current
    var prepMessage by remember { mutableStateOf("") }
    var purchaseAck by remember { mutableStateOf(false) }

package app.osmsquad

import java.text.Normalizer

/** Oyuncuyu yalnızca adla değil; ad + yaş + pozisyon + reyting ile eşleştirir. */
object Matcher {
    private val MARKS = Regex("\\p{M}")
    private val NONLET = Regex("[^a-z]")

    fun n(s: String): String = Normalizer.normalize(s.replace('ı', 'i').replace('İ', 'I'), Normalizer.Form.NFD)
        .replace(MARKS, "").lowercase().replace(NONLET, "")

    fun lev(a: String, b: String): Int {
        val d = IntArray(b.length + 1) { it }
        for (i in 1..a.length) {
            var p = d[0]; d[0] = i
            for (j in 1..b.length) {
                val t = d[j]
                d[j] = minOf(d[j] + 1, d[j - 1] + 1, p + if (a[i - 1] == b[j - 1]) 0 else 1)
                p = t
            }
        }
        return d[b.length]
    }

    fun nameOk(a: String, b: String): Boolean {
        val x = n(a); val y = n(b)
        if (x.isEmpty() || y.isEmpty()) return false
        return x == y || (minOf(x.length, y.length) >= 6 && lev(x, y) <= 1)
    }

    private fun col(c: String, r: Row): Int? = when (c) { "h" -> r.h; "d" -> r.d; "o" -> r.o; else -> null }

    /** Kaleci (col "k") reytingi listede görünmediği için reyting karşılaştırması atlanır. */
    private fun canon(p: String) = if (p == "KLC") "KL" else p

    fun match(t: AutoPlayer, rows: List<Row>): List<Row> = rows.filter { r ->
        nameOk(t.name, r.name) && (t.age == 0 || r.age == t.age) && canon(r.pos) == canon(t.pos) &&
            (col(t.col, r)?.let { it == t.rating } ?: true)
    }
}

package app.osmsquad

import android.graphics.Bitmap
import android.graphics.Rect
import com.google.mlkit.vision.common.InputImage
import com.google.mlkit.vision.text.TextRecognition
import com.google.mlkit.vision.text.latin.TextRecognizerOptions
import kotlinx.coroutines.suspendCancellableCoroutine
import kotlin.coroutines.resume

data class Ln(val text: String, val box: Rect)
data class TRow(val text: String, val y: Int)

object Ocr {
    private val rec by lazy { TextRecognition.getClient(TextRecognizerOptions.DEFAULT_OPTIONS) }
    private val CNT = Regex("""(\d{1,2})\s*/\s*20""")

    suspend fun lines(b: Bitmap): List<Ln>? = suspendCancellableCoroutine<List<Ln>?> { c ->
        rec.process(InputImage.fromBitmap(b, 0))
            .addOnSuccessListener { r ->
                c.resume(r.textBlocks.flatMap { it.lines }.mapNotNull { l -> l.boundingBox?.let { Ln(l.text, it) } })
            }
            .addOnFailureListener { c.resume(null) }
    }

    /** Aynı yatay hizadaki hücreleri tek satırda birleştirir. */
    fun rows(ls: List<Ln>): List<TRow> {
        if (ls.isEmpty()) return emptyList()
        val sorted = ls.sortedBy { it.box.centerY() }
        val tol = (sorted.map { it.box.height() }.sorted()[sorted.size / 2] * 0.6).toInt().coerceAtLeast(6)
        val groups = mutableListOf<MutableList<Ln>>()
        for (l in sorted) {
            val g = groups.lastOrNull()
            if (g != null && Math.abs(l.box.centerY() - g.map { it.box.centerY() }.average()) < tol) g.add(l)
            else groups.add(mutableListOf(l))
        }
        return groups.map { g ->
            TRow(g.sortedBy { it.box.left }.joinToString(" ") { it.text }, g.map { it.box.centerY() }.average().toInt())
        }
    }

    /** Üst çubuktaki "n / 20" sayacı; seçimlerin doğrulanması bununla yapılır. */
    fun counter(ls: List<Ln>, h: Int): Int? {
        val top = ls.filter { it.box.centerY() < h * 0.15 }.sortedBy { it.box.left }.joinToString(" ") { it.text }
        return CNT.find(top)?.groupValues?.get(1)?.toInt()
    }

    /**
     * Pitch slotuna dokununca açılan kategori seçme ekranı; dört grup başlığını
     * aynı anda gösterir ve her grubun satırında ayrı bir mavi + düğmesi bulunur.
     * Bu ekran oyuncu arama sonuçlarıyla karıştırılmamalıdır.
     */
    fun isCategoryChooser(ls: List<Ln>): Boolean {
        val groups = ls.mapNotNull { categoryGroup(it.text) }.toSet()
        return groups.size >= 2
    }

    private fun categoryGroup(text: String): String? {
        val t = Matcher.n(text)
        return when {
            t.contains("kaleci") || t.contains("goalkeeper") -> "GK"
            t.contains("defans") || t.contains("defender") -> "DF"
            t.contains("ortasaha") || t.contains("midfielder") -> "MD"
            t.contains("forvet") || t.contains("forward") || t.contains("attacker") -> "FW"
            else -> null
        }
    }

    /** Kategori seçme ekranı hariç, OSM oyuncu tablosunun başlıklarını tanır. */
    fun isList(ls: List<Ln>): Boolean {
        if (ls.isEmpty() || isCategoryChooser(ls)) return false
        val t = Matcher.n(ls.joinToString(" ") { it.text })
        val hasPrice = t.contains("fiyat") || t.contains("price")
        val hasPositionColumn = t.contains("poz") || t.contains("position")
        val hasNationalityColumn = t.contains("uyr") || t.contains("nationality")
        return hasPrice && (hasPositionColumn || hasNationalityColumn)
    }
}

    private suspend fun runAll() {
        val s = squad ?: return
        if (fgPkg() != targetPkg) { fail("Önce OSM'yi aç. Algılanan paket: ${fgPkg() ?: "yok"}"); return }
        for (p in s.players.sortedBy { it.order }) {
            currentCoroutineContext().ensureActive()
            if (p.key in done) continue
            current = "${p.name} (${p.slot} · ${p.pos})"
            render("Boş mevki → kategori + → oyuncu arama…")
            if (!preparePlayerList(p)) return
            if (!stepInList(p)) return
        }
        current = ""
        val final = capture()
        val count = final?.let { Ocr.counter(it.lines, it.h) }
        render(if (count == 20) "20/20 sayaç doğrulandı." else "20 oyuncu işlendi; son sayaç doğrulanamadı ($count). Ekranı kontrol et.")
    }

    /**
     * OSM akışı: saha/yedek yuvasına dokun → kategori ekranında ilgili satırın
     * mavi + düğmesine dokun → oyuncu arama ekranını aç.
     * Kategori başlığının kendisine dokunulmaz; her kategori için ayrı + vardır.
     */
    private suspend fun preparePlayerList(p: AutoPlayer): Boolean {
        var cap = capture() ?: return fail("Ekran görüntüsü alınamadı")
        if (fgPkg() != targetPkg) return fail("OSM ön planda değil")

        val group = Formations.groupOfPosition(p.pos)
            ?: return fail("Pozisyon grubu tanınmadı: ${p.pos}")
        var chooserOpen = Ocr.isCategoryChooser(cap.lines)
        var resultsOpen = Ocr.isList(cap.lines)

        // DEVAM'a basıldığında arama listesi veya kategori seçimi zaten açıksa,
        // aynı yuvaya tekrar dokunmadan mevcut adımdan devam et.
        if (!chooserOpen && !resultsOpen && findEditable() != null) resultsOpen = true

        if (!chooserOpen && !resultsOpen) {
            if (p.slot.startsWith("xi")) {
                val formation = Formations.all.firstOrNull { it.id == squad?.formation }
                    ?: return fail("Diziliş tanınmıyor")
                val slot = formation.slots.firstOrNull { it.id == p.slot }
                    ?: return fail("Saha yuvası bulunamadı: ${p.slot}")
                val rect = detectPitchBounds(cap.bitmap)
                    ?: return fail("Saha alanı güvenilir biçimde algılanamadı. Dokunma yapılmadı.")
                val x = rect.left + rect.width() * (slot.x / 100f)
                val y = rect.top + rect.height() * (slot.y / 100f)
                if (x !in 0f..cap.w.toFloat() || y !in 0f..cap.h.toFloat()) {
                    return fail("Saha koordinatı ekran dışında")
                }
                render("${slot.label} saha yuvası seçiliyor…")
                if (!gesture(Path().apply { moveTo(x, y) }, 70)) {
                    return fail("Saha yuvasına dokunulamadı")
                }
            } else {
                // Yedek yuvası seçimi: önce yedek alanını aç, sonra istenen boş yuvayı seç.
                if (!tapNamedNode(listOf("yedekler", "subs", "bench"))) {
                    return fail("Yedekler sekmesi tanınmadı; yanlış ekrana dokunmadım.")
                }
                delay(waitMs)
                if (!tapNamedNode(listOf(p.slot, subLabel(p.slot)))) {
                    return fail("${p.slot} yedek yuvası bulunamadı.")
                }
            }
            delay(waitMs)
            cap = capture() ?: return fail("Mevki seçildikten sonra ekran okunamadı")
            chooserOpen = Ocr.isCategoryChooser(cap.lines)
            resultsOpen = Ocr.isList(cap.lines)
        }

        if (chooserOpen) {
            render("${Formations.GROUP_NAME[group]} kategorisinin + düğmesi seçiliyor…")
            if (!tapCategoryPlus(cap, group)) {
                return fail("${Formations.GROUP_NAME[group]} satırındaki + düğmesi bulunamadı; yanlış kategoriye dokunmadım.")
            }
            delay(waitMs)
            cap = capture() ?: return fail("Kategori + düğmesinden sonra ekran okunamadı")
            if (Ocr.isCategoryChooser(cap.lines)) {
                return fail("${Formations.GROUP_NAME[group]} + düğmesine basıldı ancak kategori ekranı kapanmadı.")
            }
            resultsOpen = Ocr.isList(cap.lines)
        }

        if (!resultsOpen && findEditable() == null) {
            // Bazı OSM sürümlerinde + düğmesi önce listeyi açar, arama alanı
            // ayrıca büyüteç düğmesiyle görünür hâle gelir.
            if (!tapSearchControl(cap)) return fail("Kategori seçildi ancak oyuncu arama ekranı doğrulanamadı")
            delay(waitMs)
            cap = capture() ?: return fail("Arama ekranı okunamadı")
        }

        if (!Ocr.isList(cap.lines) && findEditable() == null) {
            return fail("Oyuncu listesi açılmadı; isim aramasına geçmedim.")
        }
        return true
    }

    private suspend fun returnToCorrectRosterScreen(p: AutoPlayer): Boolean {
        var cap = capture() ?: return false
        val isSub = p.role == "SUB"
        fun expected(c: Cap): Boolean = if (isSub) {
            c.lines.any { Matcher.n(it.text).contains("yedek") || Matcher.n(it.text).contains("bench") || Matcher.n(it.text).contains("substitute") }
        } else detectPitchBounds(c.bitmap) != null

        var attempts = 0
        while (Ocr.isList(cap.lines) && attempts < 2) {
            clearSearch()
            performGlobalAction(GLOBAL_ACTION_BACK)
            delay(waitMs)
            cap = capture() ?: return false
            attempts++
        }
        if (expected(cap)) return true
        // Bazı sürümlerde önce kategori penceresine, sonra saha ekranına dönülür.
        while (attempts < 3 && !expected(cap)) {
            if (!cap.lines.any { line ->
                    val v = Matcher.n(line.text)
                    listOf("kaleci", "defans", "ortasaha", "forvet").any { v.contains(it) }
                }) return false
            performGlobalAction(GLOBAL_ACTION_BACK)
            delay(waitMs)
            cap = capture() ?: return false
            attempts++
        }
        return expected(cap)
    }

    private fun subLabel(slot: String): String = when {
        slot.startsWith("gk") -> "Yedek Kaleci ${slot.takeLast(1).toIntOrNull()?.plus(1) ?: 1}"
        slot.startsWith("df") -> "Yedek Defans ${slot.takeLast(1).toIntOrNull()?.plus(1) ?: 1}"
        slot.startsWith("md") -> "Yedek Orta saha ${slot.takeLast(1).toIntOrNull()?.plus(1) ?: 1}"
        slot.startsWith("fw") -> "Yedek Forvet ${slot.takeLast(1).toIntOrNull()?.plus(1) ?: 1}"
        else -> slot
    }

    private fun categoryGroup(text: String): String? {
        val value = Matcher.n(text)
        return when {
            value.contains("kaleci") || value.contains("goalkeeper") -> "GK"
            value.contains("defans") || value.contains("defender") -> "DF"
            value.contains("ortasaha") || value.contains("midfielder") -> "MD"
            value.contains("forvet") || value.contains("forward") || value.contains("attacker") -> "FW"
            else -> null
        }
    }

    private fun tapCategoryPlus(cap: Cap, group: String): Boolean {
        // Aynı grup için kısa kategori başlığı ile açıklama satırını ayırt et:
        // "Kaleciler" başlıktır, "Kaleciler bölgesi için ..." ise + satırıdır.
        val matching = cap.lines.filter { categoryGroup(it.text) == group }
        val heading = matching.minByOrNull { Matcher.n(it.text).length } ?: return false
        val headings = matchingCategoryHeadings(cap.lines)
        val nextHeading = headings.filter { it.second.box.centerY() > heading.box.centerY() }
            .minByOrNull { it.second.box.centerY() }
        val previousHeading = headings.filter { it.second.box.centerY() < heading.box.centerY() }
            .maxByOrNull { it.second.box.centerY() }

        val description = matching.filter { it !== heading && it.box.centerY() > heading.box.centerY() }
            .minByOrNull { it.box.centerY() - heading.box.centerY() }
        val estimatedRowY = if (nextHeading != null) {
            (heading.box.bottom + nextHeading.second.box.top) / 2
        } else {
            // Son kategori (genellikle Kaleciler) için bölüm yüksekliğini önceki
            // başlık aralığından tahmin et; ekranın altındaki saha alanına kayma.
            val gap = previousHeading?.let { heading.box.centerY() - it.second.box.centerY() }
                ?: (cap.h * 0.16f).toInt()
            heading.box.centerY() + gap / 2
        }
        val rowY = description?.box?.centerY() ?: estimatedRowY
        val halfBand = max(44, (cap.h * 0.055f).toInt())
        val top = max(0, rowY - halfBand)
        val bottom = min(cap.h - 1, rowY + halfBand)

        // Tercih edilen yöntem: ekrandaki mavi dairesel + ikonunu görüntüden bul.
        val icon = findBluePlusCenter(cap.bitmap, top, bottom)
        if (icon != null) return dispatchTap(icon.first, icon.second)

        // WebView erişilebilirlik ağacı + düğmesine bounds veriyorsa onu kullan.
        val root = rootInActiveWindow
        var best: Rect? = null
        var bestArea = Int.MAX_VALUE
        fun walk(node: AccessibilityNodeInfo?) {
            if (node == null) return
            if (node.isVisibleToUser && node.isClickable) {
                val bounds = Rect()
                node.getBoundsInScreen(bounds)
                val rightSide = bounds.centerX() >= cap.w * 0.82f
                val inRow = bounds.centerY() in top..bottom
                val sizeOk = bounds.width() in 12..150 && bounds.height() in 12..150
                val area = bounds.width() * bounds.height()
                if (rightSide && inRow && sizeOk && area < bestArea) {
                    best = bounds
                    bestArea = area
                }
            }
            for (i in 0 until node.childCount) walk(node.getChild(i))
        }
        walk(root)
        val b = best ?: return false
        return dispatchTap(b.centerX().toFloat(), b.centerY().toFloat())
    }

    private fun matchingCategoryHeadings(lines: List<Ln>): List<Pair<String, Ln>> {
        return listOf("FW", "MD", "DF", "GK").mapNotNull { group ->
            lines.filter { categoryGroup(it.text) == group }
                .minByOrNull { Matcher.n(it.text).length }
                ?.let { group to it }
        }.sortedBy { it.second.box.centerY() }
    }

    /** Mavi + simgesinin (beyaz artı merkezli) mavi çevresini bulur. */
    private fun findBluePlusCenter(bitmap: Bitmap, top: Int, bottom: Int): Pair<Float, Float>? {
        val left = (bitmap.width * 0.82f).toInt().coerceAtLeast(0)
        val right = (bitmap.width * 0.985f).toInt().coerceAtMost(bitmap.width - 1)
        val y0 = top.coerceIn(0, bitmap.height - 1)
        val y1 = bottom.coerceIn(y0, bitmap.height - 1)
        var count = 0
        var sumX = 0L
        var sumY = 0L
        var minX = Int.MAX_VALUE
        var maxX = Int.MIN_VALUE
        var minY = Int.MAX_VALUE
        var maxY = Int.MIN_VALUE
        for (y in y0..y1 step 2) {
            for (x in left..right step 2) {
                val color = bitmap.getPixel(x, y)
                val r = (color shr 16) and 0xff
                val g = (color shr 8) and 0xff
                val b = color and 0xff
                if (b > 170 && g > 95 && b > g * 1.05f && g > r * 1.4f && b > r * 1.6f) {
                    count++
                    sumX += x
                    sumY += y
                    minX = min(minX, x); maxX = max(maxX, x)
                    minY = min(minY, y); maxY = max(maxY, y)
                }
            }
        }
        val width = maxX - minX
        val height = maxY - minY
        if (count < 18 || width !in 12..90 || height !in 12..90) return null
        return (sumX.toFloat() / count) to (sumY.toFloat() / count)
    }

    private suspend fun stepInList(p: AutoPlayer): Boolean {
        var scrolls = 0
        var lastSig = ""
        var searchTries = 0
        if (!ensureSearchField(p.name)) return fail("Arama kutusu bulunamadı")
        delay(waitMs)

        while (true) {
            currentCoroutineContext().ensureActive()
            val cap = capture() ?: return fail("Ekran görüntüsü/OCR alınamadı")
            if (fgPkg() != targetPkg) return fail("OSM ön planda değil")
            if (!Ocr.isList(cap.lines)) return fail("Oyuncu listesi ekranı kayboldu")
            val before = Ocr.counter(cap.lines, cap.h) ?: return fail("n/20 sayacı okunamadı; seçim yapılmadı")
            if (before >= 20) return fail("Sayaç zaten 20/20")

            val rows = Ocr.rows(cap.lines).mapNotNull { row -> Parser.row(row.text, row.y) }
            val matches = Matcher.match(p, rows)
            if (matches.size > 1) return fail("Birden fazla eşleşme var: ${p.name}. Yanlış oyuncu eklenmedi.")
            if (matches.size == 1) {
                val row = matches.single()
                if (!tapPlusForRow(cap, row.y)) return fail("${p.name} satırının + düğmesi bulunamadı")
                delay(waitMs)
                val afterCap = capture() ?: return fail("Ekleme sonrası ekran okunamadı")
                val after = Ocr.counter(afterCap.lines, afterCap.h)
                if (after != before + 1) return fail("${p.name} eklemesi sayaçla doğrulanamadı ($before → $after). Durdum.")
                done.add(p.key); save(); render("✔ ${p.name} eklendi ve sayaç doğrulandı")
                if (!returnToCorrectRosterScreen(p)) return fail("Oyuncu eklendi ancak sonraki yuva için saha/yedek ekranı doğrulanamadı.")
                return true
            }

            if (searchTries < retries) {
                searchTries++
                if (!replaceSearchText(p.name)) return fail("Arama yenilenemedi: ${p.name}")
                delay(waitMs)
                continue
            }
            val signature = rows.joinToString("|") { "${it.name}:${it.age}:${it.pos}" }
            if (signature == lastSig || ++scrolls > 30) return fail("Tam eşleşme bulunamadı: ${p.name} (${p.age}, ${p.pos}). Yanlış oyuncu eklenmedi.")
            lastSig = signature
            if (!gesture(Path().apply { moveTo(cap.w * 0.52f, cap.h * 0.80f); lineTo(cap.w * 0.52f, cap.h * 0.42f) }, 420)) {
                return fail("Oyuncu listesi kaydırılamadı")
            }
            delay(650)
        }
    }

    private suspend fun ensureSearchField(name: String): Boolean {
        if (findEditable() == null) {
            val cap = capture() ?: return false
            if (!tapSearchControl(cap)) return false
            delay(350)
        }
        return replaceSearchText(name)
    }

    private suspend fun replaceSearchText(name: String): Boolean {
        for (attempt in 0..retries) {
            val node = findEditable()
            if (node != null) {
                node.performAction(AccessibilityNodeInfo.ACTION_FOCUS)
                node.performAction(AccessibilityNodeInfo.ACTION_CLICK)
                delay(200)
                val args = Bundle().apply {
                    putCharSequence(AccessibilityNodeInfo.ACTION_ARGUMENT_SET_TEXT_CHARSEQUENCE, name)
                }
                val ok = node.performAction(AccessibilityNodeInfo.ACTION_SET_TEXT, args)
                delay(250)
                node.refresh()
                val currentText = node.text?.toString()?.trim()
                if (ok && currentText.equals(name, ignoreCase = true)) {
                    node.performAction(AccessibilityNodeInfo.AccessibilityAction.ACTION_IME_ENTER.id)
                    return true
                }
            }
            delay(waitMs)
        }
        return false
    }

    private fun clearSearch() {
        val node = findEditable() ?: return
        val args = Bundle().apply { putCharSequence(AccessibilityNodeInfo.ACTION_ARGUMENT_SET_TEXT_CHARSEQUENCE, "") }
        node.performAction(AccessibilityNodeInfo.ACTION_SET_TEXT, args)
    }

    private fun findEditable(): AccessibilityNodeInfo? {
        val root = rootInActiveWindow ?: return null
        var found: AccessibilityNodeInfo? = null
        fun walk(node: AccessibilityNodeInfo?) {
            if (node == null || found != null) return
            if (node.isVisibleToUser && (node.isEditable || node.className?.toString()?.contains("EditText") == true)) {
                found = node; return
            }
            for (i in 0 until node.childCount) walk(node.getChild(i))
        }
        walk(root)
        return found
    }

    private fun tapSearchControl(cap: Cap): Boolean {
        if (tapNamedNode(listOf("ara", "search", "oyuncu ara", "player search"))) return true
        val line = cap.lines.firstOrNull {
            val n = Matcher.n(it.text)
            n == "ara" || n == "search" || n.contains("oyuncuara") || n.contains("playersearch")
        } ?: return false
        return dispatchTap(line.box.centerX().toFloat(), line.box.centerY().toFloat())
    }

    private fun tapPlusForRow(cap: Cap, rowY: Int): Boolean {
        val root = rootInActiveWindow
        var point: Pair<Float, Float>? = null
        fun walk(node: AccessibilityNodeInfo?) {
            if (node == null || point != null) return
            val label = Matcher.n(node.text?.toString().orEmpty() + " " + node.contentDescription?.toString().orEmpty())
            if (node.isVisibleToUser && node.isClickable &&
                (label == "ekle" || label == "add" || label == "plus" || label == "＋" || label == "+")) {
                val b = Rect(); node.getBoundsInScreen(b)
                if (kotlin.math.abs(b.centerY() - rowY) < max(70, cap.h / 25)) point = b.centerX().toFloat() to b.centerY().toFloat()
            }
            for (i in 0 until node.childCount) walk(node.getChild(i))
        }
        walk(root)
        val p = point
        return if (p != null) dispatchTap(p.first, p.second)
        else dispatchTap(cap.w * plusX, rowY.toFloat()) // son çare: kalibre edilmiş ekran oranı
    }

    private fun tapNamedNode(names: List<String>): Boolean {
        val root = rootInActiveWindow ?: return false
        var target: AccessibilityNodeInfo? = null
        fun walk(node: AccessibilityNodeInfo?) {
            if (node == null || target != null) return
            val value = Matcher.n(node.text?.toString().orEmpty() + " " + node.contentDescription?.toString().orEmpty())
            if (node.isVisibleToUser && names.any { value.contains(Matcher.n(it)) }) {
                var candidate: AccessibilityNodeInfo? = node
                var depth = 0
                while (candidate != null && depth < 5) {
                    if (candidate.isVisibleToUser && candidate.isClickable) { target = candidate; break }
                    candidate = candidate.parent
                    depth++
                }
                if (target != null) return
            }
            for (i in 0 until node.childCount) walk(node.getChild(i))
        }
        walk(root)
        return target?.performAction(AccessibilityNodeInfo.ACTION_CLICK) == true
    }

    private fun dispatchTap(x: Float, y: Float): Boolean =
        dispatchGesture(GestureDescription.Builder().addStroke(
            GestureDescription.StrokeDescription(Path().apply { moveTo(x, y) }, 0, 60)
        ).build(), null, null)

    /** Ekrandaki en büyük yeşil saha benzeri alanın sınırını örneklemeyle bulur. */
    private fun detectPitchBounds(bitmap: Bitmap): Rect? {
        val w = bitmap.width; val h = bitmap.height
        val step = max(2, min(w, h) / 220)
        val rowCount = IntArray(h / step + 1)
        val colCount = IntArray(w / step + 1)
        var total = 0
        var y = (h * 0.08f).toInt()
        while (y < h * 0.96f) {
            var x = (w * 0.03f).toInt()
            while (x < w * 0.97f) {
                val c = bitmap.getPixel(x, y)
                val r = (c shr 16) and 0xff; val g = (c shr 8) and 0xff; val b = c and 0xff
                if (g > 55 && g > r * 1.12 && g > b * 1.05) {
                    rowCount[y / step]++; colCount[x / step]++; total++
                }
                x += step
            }
            y += step
        }
        if (total < (w / step) * (h / step) * 0.035) return null
        val minRow = rowCount.indices.firstOrNull { rowCount[it] > (w / step) * 0.22 } ?: return null
        val maxRow = rowCount.indices.reversed().firstOrNull { rowCount[it] > (w / step) * 0.22 } ?: return null
        val minCol = colCount.indices.firstOrNull { colCount[it] > (h / step) * 0.12 } ?: return null
        val maxCol = colCount.indices.reversed().firstOrNull { colCount[it] > (h / step) * 0.12 } ?: return null
        val rect = Rect(minCol * step, minRow * step, min(w, (maxCol + 1) * step), min(h, (maxRow + 1) * step))
        if (rect.width() < w * 0.45 || rect.height() < h * 0.22) return null
        return rect
    }

    private fun kbVisible(): Boolean = windows.any { it.type == AccessibilityWindowInfo.TYPE_INPUT_METHOD }

    private fun diagnose() {
        val root = rootInActiveWindow
        if (root == null) { render("TANI: aktif pencere okunamadı"); return }
        var nodes = 0; var edits = 0; var clicks = 0
        val out = StringBuilder()
        fun walk(node: AccessibilityNodeInfo?, depth: Int) {
            if (node == null || nodes > 2500) return
            nodes++
            val editable = node.isEditable || node.className?.toString()?.contains("EditText") == true
            if (editable) edits++
            if (node.isClickable) clicks++
            val text = node.text?.toString() ?: node.contentDescription?.toString()
            if ((editable || text != null) && out.length < 3500) {
                val bounds = Rect(); node.getBoundsInScreen(bounds)
                out.append("  ".repeat(depth.coerceAtMost(8)))
                    .append(node.className?.toString()?.substringAfterLast('.'))
                    .append(if (editable) " [EDIT]" else "")
                    .append(if (node.isClickable) " [CLICK]" else "")
                    .append(" [${bounds.left},${bounds.top},${bounds.right},${bounds.bottom}]: ")
                    .append(text.orEmpty()).append('\n')
            }
            for (i in 0 until node.childCount) walk(node.getChild(i), depth + 1)
        }
        walk(root, 0)
        val summary = "pkg=${root.packageName} node=$nodes editable=$edits clickable=$clicks keyboard=${kbVisible()}"
        val clipboard = getSystemService(Context.CLIPBOARD_SERVICE) as ClipboardManager
        clipboard.setPrimaryClip(ClipData.newPlainText("OSM TANI", summary + "\n" + out))
        render("TANI: $summary\nAyrıntılar panoya kopyalandı.")
    }

    private suspend fun gesture(path: Path, duration: Long): Boolean = suspendCancellableCoroutine { cont ->
        val gesture = GestureDescription.Builder()
            .addStroke(GestureDescription.StrokeDescription(path, 0, duration)).build()
        val accepted = dispatchGesture(gesture, object : AccessibilityService.GestureResultCallback() {
            override fun onCompleted(gestureDescription: GestureDescription?) { if (cont.isActive) cont.resume(true) }
            override fun onCancelled(gestureDescription: GestureDescription?) { if (cont.isActive) cont.resume(false) }
        }, null)
        if (!accepted && cont.isActive) cont.resume(false)
    }

    private suspend fun capture(): Cap? {
        val wait = 1100 - (System.currentTimeMillis() - lastShot)
        if (wait > 0) delay(wait)
        panel?.visibility = View.INVISIBLE
        delay(100)
        val bitmap: Bitmap? = try {
            suspendCancellableCoroutine { cont ->
                takeScreenshot(Display.DEFAULT_DISPLAY, mainExecutor, object : AccessibilityService.TakeScreenshotCallback {
                    override fun onSuccess(result: AccessibilityService.ScreenshotResult) {
                        val buffer = result.hardwareBuffer
                        val copied = Bitmap.wrapHardwareBuffer(buffer, result.colorSpace)?.copy(Bitmap.Config.ARGB_8888, false)
                        buffer.close()
                        if (cont.isActive) cont.resume(copied)
                    }
                    override fun onFailure(errorCode: Int) { if (cont.isActive) cont.resume(null) }
                })
            }
        } finally {
            panel?.visibility = View.VISIBLE
            lastShot = System.currentTimeMillis()
        }
        if (bitmap == null) return null
        val lines = Ocr.lines(bitmap) ?: return null
        return Cap(lines, bitmap)
    }

/** Web uygulamasındaki OCR ayrıştırıcının (parseOCR) Kotlin karşılığı; tek bir satır metnini çözer. */
object Parser {
    private val RX = Regex("""([^\d()]+?)\s*\((\d{1,2})\)\s*([^()]+?)\s+([A-ZĞÖÜİŞÇ0]{1,3})\s+(\d{1,3})\s+(\d{1,3})\s+(\d{1,3})""")
    private val LEAD = Regex("^[^A-Za-zÀ-ÿĞğİıŞşÇçÖöÜü]+")
    private val WS = Regex("\\s+")

    fun pos(t: String): String = t.uppercase(Locale("tr")).replace('0', 'O')
        .replace("SGA", "SĞA").replace("SGK", "SĞK").replace("SGB", "SĞB")

    fun row(text: String, y: Int): Row? {
        val m = RX.find(text) ?: return null
        val g = m.groupValues
        val name = g[1].replace(LEAD, "").replace(WS, " ").trim()
        return Row(name, g[2].toInt(), g[3].replace(WS, " ").trim(), pos(g[4]),
            g[5].toInt(), g[6].toInt(), g[7].toInt(), y)
    }
}

package app.osmsquad

import android.content.Context
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateMapOf
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.setValue
import org.json.JSONArray
import org.json.JSONObject
import java.text.Normalizer

fun fold(s: String): String = Normalizer.normalize(s.replace('ı', 'i').replace('İ', 'I'), Normalizer.Form.NFD)
    .replace(Regex("\\p{M}"), "").lowercase().replace(Regex("[^a-z0-9]"), "")

/** Kadro verisi cihazda saklanır. Otomasyon paylaşımı ayrı bir sözleşmeye dönüştürülür. */
class SquadState(private val ctx: Context) {
    private val prefs = ctx.getSharedPreferences("osm_squad", Context.MODE_PRIVATE)

    var formationId by mutableStateOf<String?>(null)
    var target by mutableStateOf(80)
    val players = mutableStateMapOf<String, Pl>()
    val done = mutableStateMapOf<String, String>()

    init { prefs.getString("json", null)?.let { fromJson(it) } }
    val formation: Formation? get() = Formations.all.find { it.id == formationId }
    fun slotById(id: String): Slot? = formation?.slots?.find { it.id == id } ?: Formations.SUBS.find { it.id == id }

    fun setFormation(id: String) {
        if (formationId != id) {
            players.keys.filter { it.startsWith("xi") }.toList().forEach { players.remove(it); done.remove(it) }
        }
        formationId = id
        persist()
    }

    fun updateTarget(v: Int) { target = v.coerceIn(1, 100); persist() }

    fun defaultPosition(slot: Slot): String = if (slot.id.startsWith("xi")) slot.label else when (slot.group) {
        "GK" -> "KL"; "DF" -> "STP"; "MD" -> "OS"; else -> "SF"
    }

    fun put(id: String, p: Pl): String? {
        val slot = slotById(id) ?: return "Bilinmeyen kadro yuvası"
        if (p.name.isBlank()) return "Oyuncu adı gerekli"
        if (p.age !in 1..60 || p.rating !in 1..100) return "Yaş veya reyting geçersiz"
        val pos = if (slot.id.startsWith("xi")) slot.label else p.pos.ifBlank { defaultPosition(slot) }
        if (Formations.groupOfPosition(pos) != slot.group) return "${slot.label} için $pos pozisyonu uygun değil"
        val other = players.entries.firstOrNull { it.key != id && fold(it.value.name) == fold(p.name) }
        if (other != null) return "Bu oyuncu zaten kadroda (${slotById(other.key)?.label ?: other.key})"
        if (!players.containsKey(id) && players.size >= 20) return "Kadro 20/20: önce bir oyuncu sil"
        players[id] = p.copy(name = p.name.trim(), pos = pos)
        persist()
        return null
    }

    fun remove(id: String) { players.remove(id); done.remove(id); persist() }
    fun toggle(id: String, status: String) {
        if (done[id] == status) done.remove(id) else done[id] = status
        persist()
    }
    fun resetProgress() { done.clear(); persist() }

    fun orderedSlots(): List<Slot> =
        (formation?.slots ?: emptyList()).sortedBy { Formations.GROUP_ORDER.indexOf(it.group) } + Formations.SUBS

    fun missingLabels(): List<String> = orderedSlots().filter { !players.containsKey(it.id) }.map { it.label }

    /** İş kurallarını sadece uyarı olarak değil, otomasyon öncesinde engelleyici doğrulama olarak uygular. */
    fun validationErrors(): List<String> {
        val errors = mutableListOf<String>()
        val f = formation
        if (f == null) return listOf("Önce 4-3-3A veya 5-2-3A dizilişini seç")
        if (target !in 1..100) errors += "Hedef reyting 1-100 olmalı"
        val missing = missingLabels()
        if (missing.isNotEmpty()) errors += "Eksik yuvalar: ${missing.joinToString()}"
        if (players.size != 20) errors += "Toplam oyuncu 20 olmalı (${players.size}/20)"
        if (players.values.map { fold(it.name) }.toSet().size != players.size) errors += "Aynı oyuncu birden fazla kez kullanılmış"

        f.slots.forEach { slot ->
            val p = players[slot.id] ?: return@forEach
            if (p.rating != target) errors += "${slot.label} · ${p.name}: ilk 11 reytingi $target olmalı"
            if (slot.label != "OS" && p.age !in 20..29) errors += "${slot.label} · ${p.name}: yaş 20-29 olmalı"
            if (p.pos != slot.label) errors += "${slot.label} yuvasında ${p.pos} pozisyonlu oyuncu var"
        }
        val osPlayers = f.slots.filter { it.label == "OS" }.mapNotNull { players[it.id] }
        if (osPlayers.size == 2 && (osPlayers.count { it.age in 20..29 } != 1 || osPlayers.count { it.age >= 31 } != 1)) {
            errors += "İki OS oyuncusundan biri 20-29, diğeri 31+ yaşında olmalı"
        }

        Formations.SUBS.forEach { slot ->
            val p = players[slot.id] ?: return@forEach
            if (Formations.groupOfPosition(p.pos) != slot.group) errors += "${slot.label}: pozisyon grubu uyumsuz"
            if (p.priority) {
                if (p.rating < target) errors += "${p.name}: öncelikli yedek reytingi en az $target olmalı"
                if (p.age !in 20..29) errors += "${p.name}: öncelikli yedek yaşı 20-29 olmalı"
            } else {
                if (p.rating < 50) errors += "${p.name}: normal yedek reytingi en az 50 olmalı"
                if (p.age !in 15..50) errors += "${p.name}: normal yedek yaşı 15-50 olmalı"
            }
            if (p.pos == "SĞA" && p.rating == target) errors += "Hedef reytingli SĞA yedek olamaz: ${p.name}"
        }
        return errors.distinct()
    }

    fun warnings(): Map<String, String> {
        val errors = validationErrors()
        if (errors.isEmpty()) return emptyMap()
        val result = linkedMapOf<String, String>()
        for (slot in orderedSlots()) {
            val p = players[slot.id] ?: continue
            val own = errors.filter { it.contains(p.name) || it.contains(slot.label) }
            if (own.isNotEmpty()) result[slot.id] = own.joinToString("; ")
        }
        return result
    }

    /** UI'nin kayıt formatı; eski version 2 kadroları da içe aktarılır. */
    fun toJson(): String {
        val o = JSONObject().put("version", 3).put("formation", formationId ?: JSONObject.NULL).put("target", target)
        val po = JSONObject()
        for ((k, v) in players) po.put(k, JSONObject().put("n", v.name).put("a", v.age).put("r", v.rating)
            .put("p", v.pos).put("priority", v.priority))
        o.put("players", po)
        val d = JSONObject(); for ((k, v) in done) d.put(k, v)
        o.put("done", d)
        return o.toString()
    }

    /** Otomasyon servisine version 1 veri sözleşmesi gönderir. */
    fun automationJson(): String {
        val f = formation ?: throw IllegalStateException("Diziliş seçilmedi")
        val ordered = orderedSlots()
        val arr = JSONArray()
        ordered.forEachIndexed { index, slot ->
            val p = players[slot.id] ?: throw IllegalStateException("Eksik: ${slot.label}")
            val role = if (slot.id.startsWith("xi")) "XI" else "SUB"
            val col = when (p.pos) { "KL" -> "k"; "SLB", "STP", "SĞB" -> "d"; "OS", "OOS" -> "o"; else -> "h" }
            arr.put(JSONObject().put("role", role).put("slot", slot.id).put("order", index)
                .put("name", p.name).put("age", p.age).put("club", "").put("pos", p.pos)
                .put("rating", p.rating).put("col", col).put("priority", p.priority))
        }
        return JSONObject().put("version", 1).put("formation", f.id).put("target", target).put("players", arr).toString()
    }

    /** Tüm kontroller geçerse AccessibilityService'in okuyacağı ayarı hazırlar. */
    fun prepareAutomation(purchaseRiskAcknowledged: Boolean): List<String> {
        if (!purchaseRiskAcknowledged) return listOf("Bütçe kontrolü henüz uygulanmadı. + düğmesinin satın alma yapabileceğini onaylamalısın.")
        val errors = validationErrors()
        if (errors.isNotEmpty()) return errors
        val autoJson = automationJson()
        ctx.getSharedPreferences("osm", Context.MODE_PRIVATE).edit()
            .putString("squad", autoJson).putString("done", "[]")
            .putString("pkg", "com.gamebasics.osm").putBoolean("allowPurchase", true).apply()
        done.clear()
        persist()
        return emptyList()
    }

    fun fromJson(s: String): String? {
        return try {
            val o = JSONObject(s)
            val version = o.optInt("version")
            if (version != 2 && version != 3) return "Desteklenmeyen sürüm (version 2/3 bekleniyor)"
            val fid = if (o.isNull("formation")) null else o.getString("formation")
            if (fid != null && Formations.all.none { it.id == fid }) return "Bilinmeyen diziliş: $fid"
            val valid = (Formations.all.firstOrNull { it.id == fid }?.slots?.map { it.id } ?: emptyList()) + Formations.SUBS.map { it.id }
            val po = o.getJSONObject("players")
            val tmp = linkedMapOf<String, Pl>()
            val names = hashSetOf<String>()
            for (k in po.keys()) {
                if (k !in valid) return "Geçersiz yuva: $k"
                val q = po.getJSONObject(k)
                val slot = (Formations.all.firstOrNull { it.id == fid }?.slots?.find { it.id == k } ?: Formations.SUBS.find { it.id == k })
                    ?: return "Yuva bulunamadı: $k"
                val p = Pl(q.getString("n").trim(), q.getInt("a"), q.getInt("r"),
                    q.optString("p", defaultPosition(slot)).ifBlank { defaultPosition(slot) }, q.optBoolean("priority", false))
                if (p.name.isEmpty()) return "Boş isim: $k"
                if (p.rating !in 1..100) return "Reyting 1-100 olmalı: ${p.name}"
                if (p.age !in 1..60) return "Yaş 1-60 olmalı: ${p.name}"
                if (Formations.groupOfPosition(p.pos) != slot.group) return "Pozisyon grubu uyumsuz: ${p.name}"
                if (!names.add(fold(p.name))) return "Tekrarlanan oyuncu: ${p.name}"
                tmp[k] = p
            }
            if (tmp.size > 20) return "20'den fazla oyuncu"
            val tmpDone = linkedMapOf<String, String>()
            o.optJSONObject("done")?.let { d ->
                for (k in d.keys()) {
                    val v = d.getString(k)
                    if (tmp.containsKey(k) && (v == "added" || v == "skipped")) tmpDone[k] = v
                }
            }
            formationId = fid
            target = o.optInt("target", 80).coerceIn(1, 100)
            players.clear(); players.putAll(tmp)
            done.clear(); done.putAll(tmpDone)
            persist()
            null
        } catch (e: Exception) { "JSON okunamadı: ${e.message}" }
    }

    private fun persist() { prefs.edit().putString("json", toJson()).apply() }
}
